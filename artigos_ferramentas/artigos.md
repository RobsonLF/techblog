# Artigo 1

<h1>As 5 Extensões Essenciais do VS Code para Iniciantes</h1>
<p class="meta">
  Postado em 3 de Novembro, 2025 por <strong>Robson Ferreira</strong> — 10 min de leitura
</p>

<!-- Imagem principal -->
<img src="https://code.visualstudio.com/assets/docs/editor/extension-marketplace/extensions.png" 
     alt="Extensões do Visual Studio Code" 
     class="featured-img" />

<p>
  O Visual Studio Code é um dos editores de código mais populares entre desenvolvedores — e com razão. 
  Sua flexibilidade, velocidade e enorme biblioteca de extensões o tornam uma ferramenta ideal tanto para iniciantes 
  quanto para profissionais experientes.
</p>

<p>
  Neste artigo, você vai conhecer cinco extensões que podem transformar o seu fluxo de trabalho e ajudar 
  a dar os primeiros passos no desenvolvimento de forma mais eficiente e organizada.
</p>

<h2>1. Live Server</h2>

<!-- Imagem ilustrando o Live Server -->
<img src="https://user-images.githubusercontent.com/29014463/40170828-5d78d4de-59f1-11e8-83d3-38f57367a48d.gif" 
     alt="Demonstração do Live Server" 
     class="img-section" />

<p>
  O <strong>Live Server</strong> é indispensável para quem está começando com HTML, CSS e JavaScript. 
  Ele cria um servidor local com atualização automática do navegador — ou seja, cada vez que você salva um arquivo, 
  a página recarrega sozinha.
</p>

<pre><code>// Exemplo de uso
1. Instale o Live Server na aba de Extensões (Ctrl + Shift + X)
2. Clique com o botão direito no seu arquivo HTML
3. Selecione "Open with Live Server"
</code></pre>

<p>
  Isso elimina o trabalho manual de atualizar o navegador e aumenta significativamente a produtividade durante o aprendizado.
</p>

<h2>2. Prettier - Code Formatter</h2>

<!-- Imagem do Prettier em ação -->
<img src="https://raw.githubusercontent.com/prettier/prettier-logo/master/images/prettier-banner.png" 
     alt="Prettier VS Code" 
     class="img-section" />

<p>
  O <strong>Prettier</strong> é o melhor amigo de quem quer código limpo e padronizado. 
  Ele formata automaticamente seu código seguindo boas práticas, eliminando problemas como 
  espaçamento inconsistente ou indentação incorreta.
</p>

<pre><code>// Exemplo de configuração no settings.json
"editor.defaultFormatter": "esbenp.prettier-vscode",
"editor.formatOnSave": true
</code></pre>

<p>
  Assim, toda vez que você salvar um arquivo, o Prettier ajusta a formatação automaticamente. 
  Ideal para estudantes que ainda estão se acostumando com a estrutura do código.
</p>

<h2>3. Auto Rename Tag</h2>

<!-- Imagem ilustrando o Auto Rename Tag -->
<img src="https://github.com/formulahendry/vscode-auto-rename-tag/raw/master/images/usage.gif" 
     alt="Demonstração da extensão Auto Rename Tag" 
     class="img-section" />

<p>
  Essa extensão é um verdadeiro salva-vidas para quem trabalha com HTML e JSX. 
  Ao renomear uma tag de abertura, a tag de fechamento correspondente é atualizada automaticamente.
</p>

<p>
  Exemplo: ao mudar <code>&lt;div&gt;</code> para <code>&lt;section&gt;</code>, 
  o fechamento se ajusta para <code>&lt;/section&gt;</code>. Simples, mas extremamente útil!
</p>

<h2>4. GitLens</h2>

<!-- Imagem do GitLens -->
<img src="https://gitlens.amod.io/images/gitlens-home-banner.png" 
     alt="Interface da extensão GitLens" 
     class="img-section" />

<p>
  O <strong>GitLens</strong> adiciona superpoderes ao controle de versão dentro do VS Code. 
  Ele mostra quem fez cada alteração, quando e por quê, diretamente no código.
</p>

<p>
  Além disso, permite navegar pelo histórico do Git de forma visual, 
  facilitando a compreensão do fluxo de desenvolvimento — algo essencial para quem está aprendendo a colaborar em projetos.
</p>

<h2>5. Path Intellisense</h2>

<!-- Imagem do Path Intellisense -->
<img src="https://github.com/ChristianKohler/PathIntellisense/raw/master/images/path-intellisense.gif" 
     alt="Demonstração da extensão Path Intellisense" 
     class="img-section" />

<p>
  O <strong>Path Intellisense</strong> sugere automaticamente caminhos de arquivos enquanto você digita 
  em importações, links ou referências a imagens.
</p>

<pre><code>// Exemplo de importação facilitada
import logo from '../assets/logo.png';
</code></pre>

<p>
  Ele reduz erros de digitação e economiza tempo, especialmente em projetos com muitas pastas.
</p>

<h2>Conclusão</h2>

<p>
  O Visual Studio Code é poderoso por si só, mas as extensões o tornam uma ferramenta ainda mais completa. 
  Com essas cinco opções, você terá uma base sólida para iniciar seus estudos e tornar o aprendizado de programação 
  muito mais prático e agradável.
</p>

  💡 <strong>Dica extra:</strong> explore o marketplace do VS Code! Há extensões para praticamente tudo — 
  desde temas até integração com bancos de dados e frameworks.
